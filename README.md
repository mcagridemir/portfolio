# mcagridemir.netlify.app

Personal portfolio of **Muhammed Çağrı Demir** — Senior iOS Engineer & AI/ML.

## Stack
- Pure HTML / CSS / JS — no frameworks, no build step
- Hosted on Netlify (auto-deploys from this repo)
- Contact form via Netlify Forms

## Features
- EN / DE / TR language switcher
- Dark mode
- Fully responsive (mobile, tablet, desktop)
- Typewriter, word-reveal, cursor glow animations
- Skills with Core/Supporting hierarchy + tooltips
- Netlify Forms contact
- CV embedded as downloadable PDF
- OG image, JSON-LD, sitemap, robots.txt

## Deploy
Push to `main` → Netlify auto-deploys.

## Update CV
Replace the base64 PDF in `index.html` (search for `data:application/pdf;base64`).
