# mcagridemir.github.io/portfolio

Personal portfolio of **Muhammed Çağrı Demir**: iOS engineer moving into AI/ML, M.Sc. Applied Computer Science at Ruhr-Universität Bochum.

Live: https://mcagridemir.github.io/portfolio/

## Stack
- Pure HTML / CSS / JS in a single `index.html`, with no frameworks and no build step
- Hosted on GitHub Pages; pushing to `main` deploys
- Contact form via Formsubmit
- Cloudflare Web Analytics

## Design
Blue-and-white porcelain: each section is a glazed plate on a tile wall that changes from İznik tiles to German faience as you scroll. Artwork lives in `img/`, and the credits are in the footer.

## Features
- EN / DE / TR language switcher (`translations` object, keyed by `data-i18n`; keep all three in sync)
- CV download that follows the language (`cv-en.pdf` / `cv-de.pdf`)
- Fully responsive
- OG image, JSON-LD, sitemap, robots.txt, custom 404
